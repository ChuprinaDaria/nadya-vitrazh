# Вітражний павільйон — концепт

## Ідея
Інтерактивна арт-інсталяція: шматочки вітражів обертаються на штирях (моторчики).
Коли людина підходить — вітражі зупиняються і збираються в єдине зображення.
Якщо людина дивиться в телефон або приймає фото-позу — вітражі знову починають крутитися.

## Компоненти
- **6 позицій вітражів** — кожна з ~63 окремих шматочків (PDF для лазерного різання)
- **Камера** — детекція присутності людини (YOLOv8)
- **Оцінка пози** — MediaPipe Pose (33 landmarks) → класифікація: idle / photographing / phone_viewing
- **Моторчики** — керують обертанням вітражних елементів на штирях
- **Стейт-машина** — ROTATING ↔ ASSEMBLED з проміжними станами

## Матеріали від Наді
- `матеріали павільйону/вітражі/` — 6 позицій, PDF шматочків
- `матеріали павільйону/плани/` — плани павільйону та камер з розмірами
- `матеріали павільйону/пози людини/` — референси поз для класифікатора

## Стейт-машина
```
ROTATING ──(людина стоїть N сек)──> ASSEMBLING ──> ASSEMBLED
                                                      │
                                    (людина пішла) <───┤
                                                      │
                                    (фото-поза) <──────┘
                                         │
                                    DISASSEMBLING ──> ROTATING
```

## Стек
- Python 3.11+
- YOLOv8n (person detection)
- MediaPipe Pose (pose landmarks)
- FastAPI + WebSocket (dashboard)
- OpenCV (camera)
- GPIO / Serial (motor control)
